# Concept

Терминал, служит итерфейсом, с помощью которого программы совершают ввод/вывод пользовательских данных. Терминалом может быть физический терминал или псевдо-терминал.

# Эмулятор терминала

Клиент, который отображает текстовый интерфейсю. Пример: GNOME Terminal, Konsole, xterm.

# Shell

Интерпретатор команд, работающий внутри терминала. Пример: bash, zsh, fish, ksh.

# Pseudo-Terminal

Виртульный девайс для связи приложения и интерф. польз. (виртуального терминала или ssh)

Позволяет читать ввод, делать вывод, обрабатывать сигналы, управлять строками, передевать цвета.

Состоит из пары:

* master к ней подключается ssh или эмулятор (в ядре)
* slave к ней подключается оболочка (файл девайса в /dev/pts)
