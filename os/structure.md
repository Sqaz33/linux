# Загрузчик

Grub 2/legacy, syslinux, Das U-Boot

Задача загрузчика - иниц. ядро. Он знает где оно лежит, и умеет читать его. Он также загружает начальный образ загрузки.

Grub - расширяется модулями, имеет синтаксис на подобии шелл, умеет чейнлоадить другие загрузчики (Win. Boot Managare).

# Ядро

Ядро ос (работает с posix-совм. окруж.) лежит в /boot/ и содержит в названии vmlinuz (vm - вирт. память, z - файл сжатие). В рамках одного дистр. может поддерживаться несколько вариантов ядра:

* mainline (основн.)
* lts
* rt (патченное с поддержкой исполнения в реальном времени)
* с различными патчами для повышения произв. или защ. (zen, harened)
* libre (почищенное от проприет. блобов)
* не-linux ядро

# Начальный образ загрузки

initrfd, initramfs. Архив с образом файловой системы, развернутый в оперативной пам. в начале проц. загрузки. Несет в себе драйверы и скрипты, позв. иниц. оборудование и смонтировать файловые системы.

Дестрибутивы не имеют в составе готовый начальный образ загрузки, но имеют фреймворк, чтобы собирать этот образ в зависимости от подребностей пользователя, версии ядра, железа.

* **initramfs-tools**
* **Dracut**
* **mkinitcpio**
* **make-initrd**

# init

Система инициализации. Стартует первой, PID 1, определеяет уровень запуска системы и жизненный цикл большинства служб.

# Безопасность

## PAM

Pluggable Authentication Modules - модульная система авторизации.

Отвечает за авторизацию пользователя. Модульность: модули - разделяемые библиотеки; можно задать создание домашней дирвектории, при первом входе (pam_mkhomedir.so), или смонитровать ф.с. (pam_mount.so)

su, sudo - позволяют выполнять комманды от имени другого пользователя.

Polkit - менеджер авторизации, позволяет взаимодей. непревелиг. проц. с превелиг.

LInux Security Modules (LSM) - фреймворк внутри ядра Linux, позволяющий накладывать на систему дополн. модели безопасности. Наиб. попул. SELinux, AppArmor - мандатное управление доступом: ограничивает возможности приложений, не позволяя им делать, что они хотят (но нужно настраивать).
