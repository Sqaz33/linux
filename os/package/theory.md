# Состав

* Скомпилированное приложение (или другой объект)
* Метаинформация (инф. об инф.)
  * имя пакета
  * номер версии и сборки
  * спискок файлов и ихо положение в файловой иерарх.
  * список зависимостей
  * могут быть установочные и настроечные сценарии
* Действия при установки/удалении пакета

# Конфликт

Конфликт между пакетами в основном из-за:

* одна служба на одном порту
* файл с одним имем по одному пути - apt предложит удалить другой другой пакет
* обновление одного пакеа ломает другой - dpkg откажеться устанавливать, apt обновит другой пакет

alien - утилита для конвертации одного типа пакета в другой (напр deb в rpm)
