# Модули ядра

Часть ядра, хранящияся на диске в цпециальном формате. Может загружаться по требованию и предоставлять ядру новый фукнционал.

в /lib/modules содержиться информация о зависимостях и модули. depbod -a обновить зависимости

файл ядра с рассширением ".ko"

загружать модуль с помощью modprobe, выгружать с помощью rmmod
