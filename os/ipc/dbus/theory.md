# Введение

* использует бинарные протокол
* в первую очередь для ipc в одной машине (во второую в интернете)
* работает с сообщениями
* можно сделать врапер над библиотекой d-bus для своих типов/объектов

Режимы:

* точка-точка - одно приложение взаим. с одним другим
* шина сообщений - специальное приложение, которое принимает соед. от множ. другий. прил. и пересылает междуними
